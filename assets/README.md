# Icon

`icon.png` is the shared listing logo and composer icon. The mint circular
review arrow and check mark sit on a navy rounded square; the area outside the
tile is transparent. It is designed to work on both light and dark backgrounds.

Generated with the built-in Imagegen tool for this project. The asset is included
under the repository's MIT license. No third-party brand or OpenAI logo is used.

## Generation prompt

> Use case: logo-brand. Asset type: square app icon for the independent After
> Action Review developer-agent plugin, used in Codex and a GitHub README.
> Primary request: create a polished, distinctive, extremely legible icon
> expressing a review followed by continuous improvement and the ability to
> undo. Subject: one bold almost-complete circular arrow loop surrounding a
> single crisp check mark, integrated as one balanced geometric symbol. Style:
> premium minimal vector-like flat graphic; precise generous curves, consistent
> weight, no tiny details, no three-dimensional scene. Background: a single deep
> midnight blue rounded-square tile with softly rounded corners; outside the
> tile must be truly transparent. Symbol: rich mint / jade with a very small
> warm ivory accent, excellent contrast. Composition: centered frontal mark,
> generous safe padding, square 1024 by 1024 composition. Designed to read at 32
> pixels. Constraints: no text, no letters, no words, no watermark, no robots,
> no OpenAI logo, no brand imitation, no extra objects, no gradients outside the
> tile, no mockup, no checkerboard.
